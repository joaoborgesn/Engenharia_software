# Engenharia de Software

Nesta área, estou desenvolvendo o meu portfólio pessoal e profissional da disciplina de Engenharia de Software. Aqui colocarei todas as atividades realizadas ao longo do curso.

# Sobre

Nesta disciplina, tivemos diversas aulas sobre o conteúdo de Engenharia de Software. Em todas as aulas, o professor realiza uma atividade de fixação em grupo. Como atividade avaliativa, tivemos uma prova presencial e teremos a apresentação de um trabalho sobre um determinado capítulo do livro *Engenharia de Software*, de Ian Sommerville.
